Day 1: Memory Addressing

1. Types of Memory Addresses

  • Logical Address: A segmented memory address used by the older Intel 80x86 processor architecture. It consists of a segment and an offset.
  • Linear Address (Virtual Address): A single 32-bit unsigned integer that can address up to 4 GB (up to 4,294,967,296 memory cells).
  • Physical Address: Used to address memory cells directly in RAM chips.

Note: The Memory Management Unit (MMU) translates a logical address into a linear address. The Paging Unit translates a linear address into a physical address.

2. Memory Arbiter

  • In multiprocessor systems, multiple processors usually share the same memory. A hardware circuit called a memory arbiter is inserted between the bus and every RAM chip.
  • Its role is to grant access to a CPU if the chip is free, and to delay access if the chip is currently busy servicing a request from another processor.
  • This arbiter is used even in single-processor systems to handle Direct Memory Access (DMA) conflicts.

3. Deep Dive: Logical Addresses & Segmentation

A logical address consists of two parts: a segment identifier (segment selector) and an offset.

To retrieve segment selectors quickly, the processor provides dedicated segmentation registers. There are six primary registers: cs, ss, ds, es, fs, and gs.

  • cs (Code Segment): Points to a segment containing program instructions.
  • ss (Stack Segment): Points to a segment containing the current program stack.
  • ds (Data Segment): Points to a segment containing global and static data.
  • The remaining three (es, fs, gs) are general-purpose registers.

Crucial cs Register Detail: The cs register has another important function. It includes a 2-bit field that specifies the Current Privilege Level (CPL) of the CPU. Linux only utilizes levels 0 and 3, which are referred to as Kernel Mode and User Mode, respectively.
